01 The idea

Search results are an
interface for decisions.

Before opening a page, an agent sees ranked URLs, titles, snippets, and metadata. This pre-fetch surface is where it decides to answer, search again, or spend tokens retrieving a full page.

We freeze the agent and change only the search provider. Final correctness stays close, but the evidence available, the pages opened, and the questions solved all change. Evaluating a search API means evaluating this decision surface, too.

same questions solved.

Provider choice changes which questions get solved. The overlap motivates provider-aware routing and fetch policies; this study does not evaluate a routing system.

Scope of the claim

A diagnostic study of retrieval behavior.

These findings come from one agent, one judge, three providers, and 100 hard questions collected on May 17, 2026. Actions are observational, and unfetched pages are not judged. The results characterize the tested configuration; they do not establish a universal provider ranking or a causal effect of fetching.
